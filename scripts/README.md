# Scripts de procesamiento

Esta carpeta queda reservada para scripts reutilizables de preparación de datos, automatización o exportación de insumos.

## Uso recomendado
- Transformaciones de datos.
- Cargas desde CSV u otras fuentes.
- Generación de archivos derivados para `data/processed`.

## Archivo compartido
- `grd_common.py`: utilidades comunes para los notebooks separados, incluyendo carga base, limpieza 2024 y lectura de catálogos/geojson.
